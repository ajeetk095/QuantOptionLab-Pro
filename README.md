## ✨ What it does

OptionLab Pro prices **European, American and barrier options** using two market-realistic
models instead of Black-Scholes:

| Model | Captures | Key parameters |
|---|---|---|
| **Heston** (stochastic volatility) | Volatility clustering, leverage effect, volatility skew | ν₀, κ, θ, ρ |
| **Merton** (jump-diffusion) | Sudden crash-like price jumps, fat tails | λ, µ, δ |

All pricing runs by **Monte Carlo simulation** (100,000+ paths, 100–250 steps, seeded and
reproducible), with **numerical Greeks** (Delta, Gamma), **put–call parity validation**,
a 7-strike moneyness sweep, and barrier option path monitoring.

## 📊 Headline research results

| Question | Model / Setting | Result |
|---|---|---|
| Q5 | Heston ATM Call / Put (ρ = −0.30) | $3.46 / $2.38 |
| Q6 | Heston ATM Call / Put (ρ = −0.70) | $3.49 / $2.39 |
| Q8 | Merton ATM Call / Put (λ = 0.75) | $5.10 / $9.52 |
| Q9 | Merton ATM Call / Put (λ = 0.25) | $5.74 / $6.52 |
| Q11 | Put–call parity (all cases) | Holds, gaps ≈ $0.01–0.02 |
| Q14 | Up-and-in call vs vanilla (B=K=$95) | $2.56 vs $4.19 (−39%) |
| Q15 | Down-and-in put vs vanilla (B=K=$65) | $3.52 vs $9.52 |

*Note on metrics: this is a pricing-engine study, not a supervised ML classifier — therefore
accuracy/precision/recall/F1 do not apply. The analogous quality metrics are put–call parity
gaps, greeks bounds, monotonicity in strike, and reproducibility (all validated by `pytest`).*

## 🚀 Quick start

```bash
git clone <your-repo-url> && cd optionlab-pro
python -m venv .venv && source .venv/bin/activate
pip install -r requirements.txt
streamlit run app.py
```

Docker: `docker build -t optionlab-pro . && docker run -p 8501:8501 optionlab-pro`

Full deployment guides (Streamlit Cloud, Hugging Face Spaces, Railway, Render, Replit,
Docker): see [documentation/deployment.md](documentation/deployment.md).

## 🏗️ Architecture

```
Streamlit UI (10 pages) ──► utils/pricing.py ──► Monte Carlo engines
        │                        │                  ├─ Heston Euler SV simulator
        │                        │                  ├─ Merton compound-Poisson MC
        │                        │                  ├─ Finite-difference Greeks
        │                        │                  ├─ CRR binomial American pricer
        │                        │                  └─ Barrier path monitoring
        ├─► utils/market_data.py ──► Free APIs + demo fallback
        └─► Plotly / Altair visualisation
```
